# Listen to me 🦉

เกมฝึกฟังโน้ตดนตรีสำหรับเด็ก (functional ear training) มีน้องฮูกเป็นผู้ช่วย ใช้สีประจำโน้ต (โด=แดง เร=ส้ม มี=เหลือง ฟา=เขียว ซอล=ฟ้า ลา=คราม ที=ม่วง)
เรียกโทนิกว่า “โน้ตรูท” และใช้ภาพ “บ้าน” ในเกมและ cadence (เพลงบอกบ้าน พาโน้ตกลับบ้าน) เพื่อให้เด็กเข้าใจง่าย

- **เรียนรู้คีย์** ดูโน้ตของสเกลบนคีย์บอร์ด ทั้ง 12 คีย์ในโหมดเมเจอร์, natural minor, harmonic minor และ melodic minor พร้อม key signature และฟังสเกล คอร์ดโทนิก และ cadence
- **แบบทดสอบ** แอปเล่น cadence (I–IV–V–I หรือ i–iv–V–i) เพื่อบอกคีย์ แล้วสุ่มเล่นโน้ตในคีย์ ให้ผู้ใช้ตอบว่าเป็นขั้นที่เท่าไร ถ้าตอบผิดจะเล่นโน้ตไล่กลับไปหาโทนิก (resolve) ให้ฟัง และถ้าเปิดตัวเลือกไว้ ขั้นที่เคยตอบผิดบ่อยจะถูกสุ่มออกบ่อยขึ้น
- **เลียนเสียงน้องฮูก** น้องฮูกเล่นทำนองสั้นๆ ให้เด็กกดตาม ทำนองยาวขึ้นทีละโน้ตเมื่อตอบถูก มีหัวใจ 3 ดวง เลือกให้เปียโนกระพริบตามได้ (โหมดง่าย) และบันทึกสถิติสูงสุดแยกตามคีย์และด่าน
- **อ่านโน้ต** บทเรียนบรรทัด 5 เส้นในเมนู “อ่านโน้ต” (กุญแจซอล, บนเส้น/ในช่อง, โน้ตจุดสังเกต, คำช่วยจำ) และเกม “พาโน้ตกลับบ้าน” ให้อ่านโน้ตแล้วบอกชื่อ ใช้ชื่อ C D E คู่กับ Do Re Mi แบบ C = Do เสมอ มีหัวโน้ตสีเป็นล้อช่วยที่ปิดได้ ด่าน 🚀 4 ฝึกโน้ตเส้นน้อย (A3–A5) บันทึกผลการอ่านในหน้าผลงาน และสุ่มโน้ตที่อ่านพลาดบ่อยให้ออกบ่อยขึ้น
- **จังหวะโน้ต** บทเรียนในเมนูอ่านโน้ต (ตัวกลม ตัวขาวประจุด ตัวขาว ตัวดำประจุด + เขบ็ต ตัวดำ เขบ็ต 1 ชั้น พร้อมวงกลมแสดงจำนวนจังหวะ ระบายได้ถึงครึ่งจังหวะ) และเกม “ทายจังหวะโน้ต” เคาะนับนำ 4 จังหวะแล้วเล่นเสียงโน้ต ให้ทายว่าเป็นตัวไหน จองเวลาเสียงบนนาฬิกาของ Web Audio เพื่อให้จังหวะแม่นยำ
- **คอกีตาร์** บทเรียนในเมนู “รู้จักโน้ต” (คอกีตาร์เฟรต 0–12 แตะฟังได้, สายเปล่า E A D G B E, จุดบนคอ, ดูว่าโน้ตตัวหนึ่งอยู่ตรงไหนบ้าง) และเกมคอกีตาร์ 3 แบบ: “หาโน้ตบนคอ” (บอกชื่อโน้ตกับสาย แล้วแตะช่อง), “ช่องนี้ชื่ออะไร” (ชี้ช่องให้ แล้วบอกชื่อ) และ “ฟังแล้วหาบนคอ” (ฟังเสียงแล้วหาช่อง) ด่าน 1–5 ถึงเฟรต 12 และโน้ตติดชาร์ป ใช้เสียงกีตาร์โปร่งจริง บันทึกสถิติรายช่องและสุ่มเน้นช่องที่ยังไม่แม่น
- **สเกลบนคอกีตาร์** บทเรียนในเมนู “รู้จักโน้ต” ระบบ 5 แพทเทิร์น CAGED (เฟรต 0–16) ครบ 12 คีย์ แพทเทิร์นไม่ใช้สายเปล่าเลย จึงเลื่อนไปคีย์ไหนก็รูปนิ้วเดิม พร้อมสวิตช์สลับเมเจอร์ ↔ ไมเนอร์คู่หูที่คงรูปนิ้วเดิมและย้ายแค่โน้ตรูท · ดูทั้งคอได้ และไล่สเกลขึ้น–ลงพร้อมไฮไลต์ตามเสียง
- **จับเวลาตอบ** ตั้งได้ในทุกเกม (ไม่จับเวลา / 20 / 10 / 5 วินาที) เกมทายโน้ตเริ่มนับหลังเสียงจบและหยุดระหว่างฟังซ้ำ เกมเลียนเสียงนับต่อโน้ต หมดเวลานับเป็นตอบผิด
- **สถิติ** ความแม่นยำสะสมแยกตามคีย์และขั้น (heatmap) และประวัติรอบที่ฝึก เก็บไว้ใน localStorage ของเบราว์เซอร์
- **เคล็ดลับ** แนวทางฝึกสำหรับเด็ก ความรู้สึกของโน้ตแต่ละตัว คำแนะนำสำหรับผู้ปกครองและคุณครู และแผนฝึก 4 สัปดาห์ (น้องฮูกสุ่มเคล็ดลับมาบอกก่อนเริ่มเกมทุกครั้ง)

## การรัน

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit tests (Vitest)
npm run build    # build ไปที่ dist/ สำหรับ deploy เป็นเว็บ static
```

## โครงสร้าง

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `src/theory/` | ทฤษฎีดนตรี: โน้ตในคีย์, การสะกดชื่อโน้ต, ชื่อเรียกขั้น (ใช้ `@tonaljs/tonal`) |
| `src/audio/` | เล่นเสียงด้วย Tone.js (เสียงเปียโน Salamander และใช้เสียงสังเคราะห์แทนถ้าโหลดไม่สำเร็จ), คอร์ด cadence |
| `src/quiz/` | สุ่มคำถาม, เส้นทาง resolve, สถิติ, state ของแบบทดสอบ |
| `src/components/` | คีย์บอร์ดเปียโน (SVG), ตัวเลือกคีย์, หน้าจอต่างๆ ของแบบทดสอบ |
| `src/content/` | ข้อความเคล็ดลับ (แก้ไขเนื้อหาได้ที่ `tips.ts` ไฟล์เดียว) |
| `src/echo/` | กติกาเกมเลียนเสียงน้องฮูก (ตรวจคำตอบ, ต่อทำนอง, ดาว) |
| `src/notation/` | คำนวณตำแหน่งโน้ตบนบรรทัด 5 เส้น, เส้นน้อย, หางโน้ต |
| `src/reading/` | ด่านและกติกาเกมอ่านโน้ต |
| `src/lib/` | ตัวช่วยกลาง: สุ่มแบบถ่วงน้ำหนัก, ตัวจับเวลา (`useCountdown`) |
| `src/rhythm/` | ค่าตัวโน้ตจังหวะ, ด่าน, การสุ่ม และตารางเวลาเสียงเคาะ/เสียงโน้ต |
| `src/guitar/` | การตั้งสาย, ตำแหน่งโน้ตบนคอ, ด่าน และกติกาเกมกีตาร์ |
| `src/scale/` | แพทเทิร์น CAGED (คำนวณจากสเกลจริง), ความสัมพันธ์เมเจอร์–ไมเนอร์ และบทเรียนสเกล |
| `src/storage/` | บันทึกสถิติสะสมลง localStorage |
| `src/pages/` | หน้าเรียนรู้คีย์ หน้าแบบทดสอบ และหน้าสถิติ |

## สิ่งที่วางแผนทำต่อ

- กีตาร์: โหมดถนัดซ้าย (ยังไม่ทำ)
- จังหวะ เฟส B: เกมเลือกรูปแบบจังหวะ 1 ห้อง, สถิติจังหวะ, ตั้งความเร็ว · เฟส C: เกมเคาะตาม, ตัวหยุด
- อ่านโน้ต เฟส C: เกมเล่นตามโน้ต, กุญแจฟา, คีย์ที่มีชาร์ป/แฟลต
- ทายทำนองสั้นๆ หลายโน้ต และโน้ตนอกคีย์ (chromatic)
- ทำเป็น PWA ใช้แบบออฟไลน์ได้ (เก็บไฟล์เสียงเปียโนไว้ในโปรเจค)

## Deploy

เป็นเว็บ static ทั้งหมด (`npm run build` → โฟลเดอร์ `dist/`) นำขึ้น Vercel, Netlify, Cloudflare Pages หรือ GitHub Pages ได้
ใช้ build command `npm run build` และ output directory `dist`
